## 🤝 Онлайн-функции: сообщество, сервер, спонсорство 10%, подарки и трейдинг

- **Сервер сообщества зашит в игру**: `https://shkoladrop.onrender.com` — клиент подключается автоматически, ничего настраивать не надо. Свой сервер поднимается одной командой: `node server/index.js` (Node 18+, ноль npm-зависимостей) → http://localhost:3377.
- **💬 Сообщество** (экран «Фарм» → карточка «Сообщество»): статус сервера (онлайн/оффлайн) всегда наверху, общий чат школы и поиск игроков по уникальному ID.
- **🆔 Уникальные ID**: каждому аккаунту при первом входе в обновлённую версию сервер автоматически присваивает ID вида `#123456` — он остаётся навсегда и показывается в профиле и сообществе.
- **✔ Галочки верификации**: выдаются администрацией в админ-панели (список всех зарегистрированных игроков с их ID) и видны в чате, профиле и в поиске игроков.
- **☁️ Облачное сохранение**: прогресс сам заливается на сервер каждые ~45 секунд и при выходе со страницы; при входе восстанавливается автоматически (ручной JSON-экспорт/импорт из настроек убран).
- **💜 Коды авторов (спонсорство)**: игрок вводит код на экране «Фарм», и **10% от стоимости его кейсов копится владельцу кода** (с игрока ничего не списывается). Реестр — файл **`author-codes.json`** в корне репо: `code` + `ownerUid` (id аккаунта автора) + `ownerName`.
- **🎁 Подарки**: предмет из рюкзака другому игроку по уникальному ID, нику или id аккаунта.
- **🤝 Трейдинг**: комнаты обмена по 6-значному коду, атомарный обмен и выдача предметов обеим сторонам.
- **🛠 Админка**: список игроков с галочками верификации, официальные сообщения в общий чат (и модерация — удаление сообщений), выдача кодов авторов.
- Клиент — `js/netplay.js`; при оффлайн-сервере спонсорство копит 10% в очередь и отправит её при появлении связи.

### Прокрутка и навигация (v2.0.2)
- **Обычная прокрутка страницей**: никаких «каркасов» с фиксированной высотой — игра скроллится пальцем/колесом в любом браузере и внутри iframe предпросмотра.
- Критический CSS (прокрутка + нижнее меню) встроен прямо в `index.html`, поэтому работает даже если внешний файл стилей закэширован.
- **Нижнее меню закреплено и видно всегда**: Апгрейд · Кейсы · Рюкзак · Фарм · Лавка, тап-зоны от 46px. Шапка «прилипает» сверху.

- Вложенные «мелкие» скроллбары убраны: рюкзак, лавка, дежурство и достижения прокручиваются вместе с экраном.

- Блокировка прокрутки под модалками управляется единым механизмом (`body.modal-open`) — «залипшего» скролла больше нет.
- Смена вкладки автоматически возвращает контент к началу.

### Адаптация под «железо» устройства
- **Автовыбор качества графики**: учитываются ядра CPU, объём памяти, экономия трафика, системная настройка «меньше анимаций» и живой замер FPS после запуска.

- В настройках — переключатель **Авто / Высокое / Низкое** и строка с данными устройства (ядра, память, FPS, разрешение).
- Поля ввода 16px — iOS не зумит страницу при фокусе; `100dvh` и safe-area для вырезов экрана.

server/selftest.js         — самотест сервера: node server/selftest.js (50 проверок)

## 🍪 Cookie и сохранения

| Cookie | Срок | Назначение |
| --- | --- | --- |
| `shkola_consent` | 12 мес | твой выбор в окне согласия (обязательный) |
| `shkola_meta` | 12 мес | версия, стрик награды, последний визит, промокоды, флаг «кот найден» |
| `shkola_settings` | 12 мес | звук, громкость, тема, быстрый режим (категория «Настройки») |
| `shkola_stats` | 3 мес | локальная статистика сессий (категория «Статистика») |
| `shkola_save_0..2` | 12 мес | компактная резервная копия прогресса |

Версия: **3.5+** — сообщество с чатом и уникальными ID, галочки верификации, облачные сохранения, кэш-бастинг ссылок.

**Как вернуть прогресс из версии 1.0:** не удаляй данные сайта в браузере. Старое сохранение (`shkola_drop_save_v7`) переносится автоматически при первом запуске; если ты уже сбросил прогресс — открой ⚙️ «Настройки» → кнопка «↩️ Вернуть прогресс из версии 1.0» (появляется, пока старый ключ жив).

Основное сохранение лежит в `localStorage` под ключом `shkola_drop_save_v8`. Отключение категории «Игровые сохранения» удаляет сохранённый прогресс и переводит игру в режим без сохранений (до закрытия вкладки).
