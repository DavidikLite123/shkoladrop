# 🖥 Как запустить сервер ШКОЛА ДРОП (аккаунты + сообщество + чат + подарки + трейдинг + спонсорство 10%)

> 🆕 **Сервер v1.2.0 / сезон 3.7**: добавились e-mail аккаунты (`/api/account/*`) и,
> при ПЕРВОМ запуске этой версии, **одноразовый вайп экономики**: сервер чистит
> облачные сейвы, подарки, трейды и выдачу, но БЕРЕЖНО сохраняет игроков
> (ник + уникальный ID + галочка), e-mail аккаунты, спонсорку и чат.
> Для данных лучше подключить постоянный диск (см. п.4) — иначе после вайпа
> новый прогресс тоже пропадёт при следующем ресоздании контейнера.

> ⚡ **В игру уже зашит боевой сервер сообщества: `https://shkoladrop.onrender.com`** —
> игрокам ничего настраивать не нужно. Этот гайд — про поднятие СОБСТВЕННОГО
> сервера (для тестов или переезда на своё железо).

Это **лёгкий сервер на Node.js без каких-либо зависимостей** — ничего устанавливать
через npm не нужно. Он умеет:

- 🔐 **Аккаунты (сезон 3.7)** — e-mail + пароль + 6-значный код «из письма»
  (демо-режим: SMTP нет, код возвращается прямо в ответе API и показывается в игре).
  Возвращение в свой аккаунт с любого устройства за 2 минуты; пароль хранится
  только солёным SHA-256 хешем, код живёт 10 минут, 6 неверных попыток — код сгорает;
- 💬 **Сообщество** — общий чат школы, уникальные ID игроков вида `#123456`, галочки верификации ✔;
- ☁️ **Облачные сохранения** — автоматический бэкап прогресса и восстановление после входа;
- 🛠 **Админ-инструменты** — список зарегистрированных игроков, выдача галочек, официальные сообщения в чат, модерация;

- 🎁 **Подарки** — игрок → игрок по уникальному ID, нику или id аккаунта;
- 🤝 **Трейдинг** — комнаты обмена по 6-значному коду, атомарный обмен предметами;
- 💜 **Коды авторов и спонсорство 10%** — игрок вводит код автора, и 10% от
  стоимости его кейсов копится владельцу кода;
- 🛠 **Админ-выдача кодов авторов** — прямо из админ-панели игры, с записью
  в `author-codes.json`;
- 🌐 раздача самой игры — **одна команда поднимает и сайт, и API**.

> Без сервера игра работает как раньше (оффлайн-режим): спонсорство тоже
> работает, но 10% копятся в очереди и уйдут автору, когда сервер появится.
> Подарки и обмен требуют запущенный сервер.

## 1. Самый простой запуск (у себя на компьютере)

1. Поставь **Node.js 18 или новее**: https://nodejs.org (кнопка LTS). Проверка:
   ```bash
   node -v        # v18+ / v20+ / v22+ — всё ок
   ```
2. Открой терминал в папке проекта и запусти:
   ```bash
   node server/index.js
   ```
3. Открой в браузере: **http://localhost:3377** — это и игра, и API (один процесс).
   В игре: меню **⋮ → «Трейдинг и подарки»** — индикатор должен быть зелёным «ОНЛАЙН».

Остановка сервера: `Ctrl + C` в терминале. Данные лежат в `server/data/db.json`
(создаётся сам при первом запуске — можешь открыть и починить руками, это обычный JSON).

### Смена порта
```bash
# Windows (cmd):
set PORT=8080 && node server/index.js
# Windows (PowerShell):
$env:PORT=8080; node server/index.js
# Linux/Mac:
PORT=8080 node server/index.js
```

### Проверка, что всё работает
```bash
node server/selftest.js
# должно быть: 74 passed, 0 failed
```
Самотест поднимает сервер на временном порту с временной базой и гоняет ВСЕ методы:
аккаунты (регистрация, верный/неверный код, неверный пароль, повторный вход),
одноразовый вайп сезона 3.7 (старый прогресс стирается, аккаунты/ID/галочки живут,
после вайпа новый прогресс рестартом не сносится), уникальные ID и галочки,
чат (включая админский и удаление), облачные сейвы, спонсорство 10%,
вывод автору, админ-выдача кода, подарки, обмен с отменой.

## 2. Коды авторов (файл author-codes.json)

Список кодов авторов лежит в **корне репозитория — `author-codes.json`** (обычный
файл в GitHub). Сайт и сервер читают один и тот же файл.

Формат записи:

```json
{ "code": "MURKATV", "ownerUid": "player-demo-murka", "ownerName": "Мурка ТВ" }
```

- **code** — то, что игрок вводит в игре (раздел «💜 Спонсорство · Код автора» на экране «Фарм»);
- **ownerUid** — **id аккаунта** владельца кода. Каждый игрок видит свой id в
  профиле (Профиль → «id аккаунта», есть кнопка-копия 📋) и в окне «Трейдинг и подарки»;
- **ownerName** — отображаемое имя (его видят игроки);
- **royaltyPercent** (вверху файла) — процент автору, по умолчанию **10**.

### Как выдать код автору (два способа) — можешь только ты

**Способ А — через админ-панель игры** (когда сервер запущен):
1. Попроси ютубера скопировать свой **id аккаунта** (Профиль → id аккаунта).
2. В игре: 5 кликов по логотипу 🎒 → введи код доступа (только у автора проекта) → «Панель разработчика».
3. Секция **«💜 Выдать код автора»**: вставь id аккаунта, имя и (опционально) желаемый код →
   «Выдать код автора». Код **автоматически допишется в `author-codes.json`** на сервере.

**Способ Б — руками через GitHub** (сервер не нужен):
1. Открой `author-codes.json` в репозитории → ✏ Edit.
2. Добавь строку в массив `"codes"` (запятую не забудь), коммить. Vercel сам задеплоит.
   Если админ-панель открыта без сервера — она сама сгенерирует тебе строку для вставки.

> Игроки вводят код на экране **Фарм → «💜 Спонсорство · Код автора»**. Каждый
> открытый ими кейс копит 10% от его цены автору. У игрока деньги НЕ списываются —
> доля автору начисляется «от проекта», как в фортнайт-поддержке.

### Как автор кода получает свои 10%
1. Запусти сервер (см. выше).
2. Автор заходит в игру со **своего аккаунта** (тот, чей id указан в `ownerUid`).
3. На экране **Фарм** в карточке спонсорства появится блок **«Мой код автора»**:
   накоплено, сколько игроков, кнопка **«Забрать накопленные 10%»** — деньги придут на баланс.

## 3. Подарки и трейдинг

1. Оба игрока запускают игру **на том же сервере** (один и тот же адрес).
2. Даритель: **⋮ → «Трейдинг и подарки»** → вкладка «🎁 Подарить» → выбрать
   предмет из рюкзака → вставить **id аккаунта** (или ник) получателя → отправить.
3. Получатель: вкладка **«📥 Входящие»** → «Забрать» (при входе в игру есть
   уведомление и красная точка на кнопке ⋮).
4. **Обмен**: «🤝 Обмен» → создать комнату → отправить другу **код из 6 символов** →
   друг вводит код, прикладывает свой предмет и подтверждает обмен → оба предмета
   приходят во «Входящие». Отмена комнаты возвращает предмет владельцу.

Сервер атомарно раздаёт предметы: либо обмен прошёл целиком, либо не прошёл вообще —
дупликации и «слипшиеся» сделки исключены. Предмет, выставленный в обмен,
уходит из рюкзака сразу; при отмене вернётся.

## 4. Вынести сервер в интернет (чтобы друзья заходили из разных городов)

Серверу хватит **самого слабого VPS** (1 CPU / 512 МБ) или бесплатного Node-хостинга.

**Вариант 1: VPS (_tim VDPS/таймвеб и т.п.) — 5 минут**
```bash
# на VPS:
git clone https://github.com/DavidikLite123/shkoladrop.git
cd shkoladrop
PORT=80 ADMIN_SECRET=придумай-настоящий-секрет node server/index.js
# сайт и API: http://IP-ТВОЕГО-VPS  (лучше прикрутить домен + HTTPS nginx/caddy)
```

**Вариант 2: бесплатный хостинг (Render/Railway и т.п.)**
- New project → из GitHub-репозитория → build command: *пусто* →
  start command: `node server/index.js` → переменная `PORT` обычно выдаётся сама, 
  `ADMIN_SECRET` задай свой.
- ⚠️ **ВАЖНО (Render)**: бесплатный инстанс «засыпает» без трафика — в игре для этого
  есть кнопка «⚡ Включить сервер» и почта поддержки shkoladrop.contact@gmail.com.
  А ещё у эфемерного инстанса **диск стирается при редеплое**: чтобы база
  `server/data/db.json` (аккаунты! чат! начисления!) переживала рестарты,
  в панели Render подключи **Persistent Disk** на путь `server/data`
  (или задай переменную `SHKOLA_DATA_DIR=/opt/render/project/data` и примонтируй его туда).

**Важно про Vercel:** текущий сайт на Vercel — статичный, там сервер НЕ живёт.
Игра подключается к зашитому серверу сообщества `https://shkoladrop.onrender.com` автоматически.
Для отладки своего сервера: админ-панель → «🖥 Адрес игрового сервера» → вставь URL
(сохранится только в твоём браузере; пустое поле возвращает зашитый боевой сервер). Или раздавай игру
самим сервером (он уже умеет статику) — тогда НИЧЕГО настраивать не надо вообще.

### Про секрет админки
- По умолчанию: `david-admin-1337`. **Обязательно поменяй**, если сервер торчит в интернет:
  ```bash
  ADMIN_SECRET=длинная-строчка node server/index.js
  ```
- Тот же секрет впиши один раз в браузере: консоль →
  `localStorage.setItem('shkola_admin_secret','длинная-строчка')` — админ-кнопки начнут работать.

## 5. Частые вопросы

| Проблема | Решение |
|---|---|
| «Сервер оффлайн» в игре | Сервер запущен? Адрес в админ-панели верный (без `/` в конце)? Нет блокировки mixed-content: http-сервер + https-сайт не дружат — нужен HTTPS на сервере или раздавать сайт тем же сервером. |
| Индикатор «ОНЛАЙН», но уникальный ID не выдаётся | Обновлённый клиент запрашивает ID сам и повторяет попытку, пока сервер не оживёт (Render просыпает 30–90 с). Ускорить: ⋮ → «Сообщество» (кнопка ID сразу шлёт sync) или «⚡ Включить сервер». Если аккаунт перенесён из очень старого сейва без uid — клиент чинит uid автоматически. |
| Код автора «не находится» | Проверь `author-codes.json`: валидный JSON, код в массиве `codes`. Сайт кэширует реестр ненадолго — обнови страницу. |
| Куда пишутся деньги автора | `server/data/db.json` → `earnings`. При выводе — обнуляется локально на сервере и начисляется в игру. |
| Подарок «получатель не найден» | По нику можно дарить только тем, кто хоть раз зашёл в игру с этим сервером. Попроси id аккаунта — по id работает всегда. |
| Всё сломалось | Останови сервер (`Ctrl+C`), удали `server/data/db.json` (вернёт чистую базу), запусти снова. Сейвы игроков в их браузерах не пострадают. |
