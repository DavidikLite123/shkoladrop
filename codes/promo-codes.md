## Как выглядят коды

Случайные буквы и цифры блоками по четыре: `XXXX-XXXX-XXXX`. Никаких читаемых слов —
угадать по смыслу нельзя. Алфавит без похожих символов: **нет `0`, `O`, `1`, `I`**
(чтобы код легко диктовать и перепечатывать без ошибок).

- Регистр не важен — игра сама приводит ввод к верхнему регистру.
- Пробелы не важны — они вырезаются.
- Дефисы можно не печатать: `ABCD-EFGH-JKLM` = `ABCDEFGHJKLM`.
- Один код — одно использование на аккаунт (список использованных: `stats.promosUsed`).

## Как добавить ещё

1. Сгенерировать код (Node, без зависимостей):
   ```bash
   node -e "const A='ABCDEFGHJKLMNPQRSTUVWXYZ23456789';const r=require('crypto');\
   console.log(Array.from({length:3},()=>Array.from({length:4},()=>A[r.randomInt(A.length)]).join('')).join('-'))"
   ```
2. Добавить строку в `PROMO_CODES` (`js/config.js`):
   ```js
   'XXXX-XXXX-XXXX': { money: 100000, xp: 150, label: 'Описание для игрока' },
   ```
   Поля: `money` — деньги, `xp` — опыт, `item` — id предмета из каталога
   (например `cat_gora_bogdan`, `upg_gold_whistle`), `label` — текст в уведомлении.
3. Не начинай код с `ADMIN` (это служебный вход в админку) и с `VIP-` (это VIP-коды).
